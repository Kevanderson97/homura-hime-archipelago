AI was used during development in the following ways:

1. To quickly explore the game's files and scenes via the Unity Explorer MCP. This was especially helpful since this game disables mouse input, so I couldn't manually use Unity Explorer at the beginning.
2. To generate code for most of the codebase based on my architecture and implementation plan. 

I understand how the code works and have been a Unity developer for many years. Code I have publicly hosted online was certainly used in training these AIs, so I feel justified using them. At some point I'll go through and clean up the implementation a bit, but I'm not unhappy with how the AI has done it, so I'm not planning to go through and remove all generated code.

The only AI generated portions of the project are code, based on a detailed, human-made implementation plan.
